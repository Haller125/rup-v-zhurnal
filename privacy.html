РУП в журнал

Политика конфиденциальности

Редакция от 30.10.2026 · версия расширения 0.4.0

Коротко: расширение работает только в браузере пользователя. У него нет своего сервера, аналитики и рекламы. Разработчику и третьим лицам данные не передаются. Запросы уходят только на сайт журнала SmartNation College и только по команде пользователя.

Расширение «РУП в журнал: помощник для SmartNation» (далее «расширение») помогает преподавателю перенести темы из рабочей учебной программы (РУП) в колонки электронного журнала SmartNation College. Разработчик: Кабаш Е., связь: erokkabash1@gmail.com.

Расширение не является продуктом SmartNation и не связано с ТОО «Bilim Technology».

2. Где хранятся данные

  • Сохранённые расписания хранятся только в браузере пользователя, в локальном хранилище расширения (chrome.storage.local). Встроенные расписания копируются туда при первом открытии журнала. Расписания удаляются кнопкой «Удалить» в панели или вместе с расширением.
  • Содержимое РУП и данные журнала хранятся только в памяти открытой вкладки и пропадают при её закрытии.
  • По команде пользователя расширение сохраняет на его компьютер файлы: расписание и план колонок в формате JSON.

3. Кому передаются данные

  • Разработчику расширения и третьим лицам данные не передаются. У расширения нет своего сервера, аналитики, рекламы и счётчиков.
  • Расширение отправляет запросы только на сайт college.smartnation.kz и только по команде пользователя: чтение сведений о журнале и создание колонок с датой, темой и количеством часов. Это те же запросы, что выполняет сам интерфейс журнала, они идут от имени пользователя, который уже вошёл в SmartNation.
  • Расширение не загружает и не исполняет код с внешних адресов.
  • Расширение не продаёт данные и не использует их для рекламы, оценки кредитоспособности или любых целей, не связанных с заполнением журнала.

4. Права расширения в браузере

  • Доступ к страницам https://college.smartnation.kz/*/mng/control/journals/*: чтобы показать панель на странице журнала и выполнять запросы к журналу от имени пользователя.
  • storage: чтобы хранить расписания пользователя в его браузере.

5. Персональные данные

Расширение предназначено для преподавателей. ФИО преподавателей из расписания и журнала обрабатываются только на устройстве пользователя. Разработчик не получает и не хранит персональные данные пользователей.

6. Изменения политики

Если в будущих версиях появятся учётные записи, лицензии или обработка РУП на сервере разработчика, политика будет обновлена до выпуска такой версии, а в описании расширения будет указано, какие данные и зачем передаются.

English summary

The Chrome extension “РУП в журнал” (RUP to Journal) helps a teacher create lesson columns (date, topic, hours) in the SmartNation College e-journal from their curriculum document. It runs entirely in the user's browser.

  • It ships the public class timetables of the Polytechnic college and copies them to local storage on first use.
  • It reads the curriculum file the user selects, the class timetable the user enters, and the journal page the user has open. It never requests student lists; student marks returned by the journal are not used or stored.
  • Timetables are stored only in chrome.storage.local on the user's device. Everything else lives in the open tab's memory.
  • Requests go only to college.smartnation.kz, only when the user clicks, using the user's existing session. No data is sent to the developer or any third party. No analytics, ads or remote code.
